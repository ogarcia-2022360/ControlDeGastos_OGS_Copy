# ControlDeGastos_OGS

Este proyecto está diseñado para gestionar y llevar un registro claro de los movimientos financieros de manera sencilla y segura.

---

## ¿Como se creo este proyecto?

El proyecto fue inicializado utilizando la herramienta y los comandos de Angular CLI, configurando la aplicacion bajo una arquitectura basada en componentes. 
---

## Componentes Generados:

Se crearon los siguientes componentes principales:

- login: Usado para la vista principal de acceso, contiene campos de usuario y contaseña.

- dashboard (se usara en un futuro): Se usara para mostrar la pantalla principal una vez que el usuario inicie sesion correctamente

## Tecnologías utilizadas
* **Angular:** El framework principal para crear la interfaz y la estructura de la app.
* **TypeScript & HTML/CSS:** Para la lógica y el diseño visual personalizado de las pantallas.
* **JWT (JSON Web Token):** Simulado en el navegador para mantener la sesión segura del usuario.
* **PostgreSQL:** Se usara en un futuro como una base de datos para la aplicacion.
